# archive

Undergraduate coursework, early web projects and old portfolio sites from 2021 to 2025, collected from
25 separate repositories into one. Each folder keeps its original commit history (run `git log -- <folder>`).
Nothing here is maintained; it is kept for the record. Current work is in
[research](https://github.com/rajandasguptaml/research) and on [rajandasguptaml.github.io](https://rajandasguptaml.github.io/).

## What was removed

To keep the repository small and free of third-party or accidental files, the following were deleted from
history before merging:

- `portfolio-sites/hugo-academic-cv`: a home directory that had been committed by mistake (`.vscode/`, `.p2/`,
  `.eclipse/`, `.config`, `.cache`, `.lesshst`, `.bash_history`), plus Hugo build output (`public/`,
  `resources/_gen/`, `hugo_stats.json`, `.hugo_build.lock`).
- `portfolio-sites/hugo-academic-cv-repush`: the same Hugo build output.
- `coursework/learning-laravel-summer-2021`: `public/vendor/` (1,818 third-party asset files).
- `competitive-programming`: 41 compiled `.exe` files.
- `portfolio-sites/portfolio-2021`: one gallery image larger than 5 MB.

Only each repo's default branch was merged. Pet-Care, WT_Sp21_HTML_LAB3 and WT_Sp21_HTML_mid also had
`gh-pages` branches (generated deploy copies), and the two Hugo repos had a second `master`/`Master` branch; those
were not carried over.
